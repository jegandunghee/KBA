# My Dev Blog Portfolio

이 프로젝트는 기존 관공서(한국방송협회) 클론 코딩을 전면 리팩토링하여 만든 **프론트엔드 개발자 개인 블로그 및 포트폴리오 웹사이트**입니다.

## 🚀 프로젝트 소개
단순한 마크업 복제(Clone)를 넘어, UI/UX를 개선하고 다국어 지원, 모바일 반응형 최적화, 애니메이션 등 다양한 기능을 바닐라 자바스크립트로 직접 구현했습니다.

## 🛠 기술 스택
- **HTML5 & CSS3 (SCSS)**
- **Vanilla JavaScript (ES6+)**
- **반응형 웹 디자인 (Media Queries)**

## ✨ 주요 기능
1. **다국어 지원 (i18n):** KOR / ENG 언어 토글 기능을 구현하여 실시간으로 전체 텍스트 번역.
2. **모바일 반응형 최적화:** 데스크탑, 태블릿, 모바일까지 부드럽게 이어지는 레이아웃.
3. **애니메이션 및 슬라이드:** 
   - 메인 헤더 배너 2초 간격 자동 슬라이드
   - 하단 파트너 로고 무한 롤링(Infinite Marquee) 슬라이드
4. **인터랙티브 탭 메뉴:** 주요 포스트 영역의 탭 클릭 시 해당 콘텐츠 동적 노출.

## 🎨 UI/UX 디테일
- 모든 클릭 가능한 요소에 `cursor: pointer` 적용
- 플랫하고 모던한 일러스트 썸네일 사용
- 고해상도 투명 SVG 파비콘(Favicon) 적용

## 💻 실행 방법
```bash
# 로컬 서버를 통해 실행 (VS Code Live Server 확장 프로그램 추천)
1. 프로젝트 폴더를 VS Code로 엽니다.
2. index.html 파일에서 우클릭 후 'Open with Live Server'를 클릭합니다.
```
